# Segurança

O will-repo guarda o token do GitHub no Gerenciador de Credenciais do Windows, roda comandos git nos seus repositórios e pode assinar commits. Uma falha aqui pode expor credenciais ou código, então reportes de segurança têm prioridade.

## Versões suportadas

Só a [última versão](https://github.com/WiliamMP/will-repo/releases/latest) recebe correções. O app avisa quando sai uma versão nova.

## Como reportar

**Não abra issue pública.** Use o [reporte privado de vulnerabilidade](https://github.com/WiliamMP/will-repo/security/advisories/new) do GitHub.

Inclua, se puder:

- o que a falha permite (ex.: vazar o token, executar comando, escrever fora do repositório);
- passos para reproduzir ou uma prova de conceito;
- versão do will-repo e do Windows.

Você recebe resposta em até 7 dias. Depois de corrigida, a falha é publicada num aviso de segurança com crédito para você, se quiser.
